Reputation

tasqnetwork.io/benchmark/reputation

Each period a node's reputation moves toward its observed success rate with decay μ = 0.9. A node below Rmin = 0.8 stops receiving work. The question is whether that rule removes bad nodes quickly without punishing honest ones that occasionally fail. 20,000 nodes, 300 periods.

There is a sharp boundary between 10% and 20% faults. That is the intended behaviour for these parameters, but it means a node with an unreliable network link around 15% could be excluded. Final values of μ and Rmin will be set from testnet data.
